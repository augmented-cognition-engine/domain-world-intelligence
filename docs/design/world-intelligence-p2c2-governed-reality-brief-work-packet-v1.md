# P2C2 — official-record Reality Brief into reviewed action

Status: **implemented candidate for World Intelligence 0.9.0; released-artifact reproduction pending ACE Core 0.5.0**

## Objective

Prove one honest public-data product journey across the three ACE layers without moving domain
vocabulary or action authority across their boundaries:

```text
Domain Pack configuration
  + exact official-source adapter profiles
  → Core-governed LIVE Observations and entity snapshots
  → Intelligence Shift, Signal, routing, and cited Brief
  → Core Decision, exact human review, execution, verification, and promotion
```

## Frozen scenario

The monitor follows the latest admitted Federal Communications Commission publication using two
exact Federal Register API records:

- `2026-15932`, a Notice published 2026-08-06;
- `2026-16197`, a Proposed Rule published 2026-08-07.

Both map to one stable entity,
`entity:monitor/fcc-latest-federal-register-publication`. The declarative detector watches
`document_number` and admits only the exact reviewed transition `2026-15932 → 2026-16197`.

## Ownership boundaries

| Layer | Owns in this packet | Must not own |
|---|---|---|
| ACE Core | immutable storage, runtime authority, reasoning receipts, Decision contract, effect-free preparation, review, action admission/terminal, verification, promotion | FCC, Federal Register, publication, Reality Brief semantics |
| ACE Intelligence | LIVE ingress bridge, categorical delta interpretation, routing, grounded synthesis, replay | FCC-specific transition values or source profiles |
| World Domain + adapter | entity and field vocabulary, exact source mappings, transition declaration, personas, Brief template, reviewed source allowlist | persistence, hidden control flow in the pack, authority, reasoning runtime, action execution |

The Domain Pack is JSON-only. Executable source acquisition remains a separately versioned adapter.
The create-only workspace effect remains Core's independently packaged reference adapter.

## Acceptance gates

1. Compile the new five-module pack through the unchanged public compiler.
2. Admit both exact source records as LIVE Observations and LIVE Entity Snapshots.
3. Preserve one stable entity identity and ordered baseline/current state.
4. Derive one configured categorical Shift and one routed Signal through the public LIVE bridge.
5. Produce one LIVE Brief through Core-governed reasoning with exactly two citations and six claims.
6. Reopen the Brief without a second provider call.
7. Persist a named human Decision that authorizes only `create_workspace_export`.
8. Prepare and authorize an effect-free exact action plan before a second human review.
9. Create one new workspace file, verify its exact content, then record a separate promotion.
10. Reopen the terminal action without a second file effect.
11. Keep autonomous publishing, political persuasion, voter targeting, and pack-owned action
    authority false.
12. Pass the complete World suite, adapter suite, lint, cross-repository source checkout, and later
    released-artifact reproduction.

## Explicit limits

- The accepted source transport is recorded and network-free. It contains exact official public
  records but does not prove freshness at test time.
- The monitored field changes between two admitted publications; ACE does not infer legal effect,
  policy outcome, or practical impact from the metadata alone.
- The only effect is a create-only local workspace file after exact human review.
- Cross-run Decision and action identities include real execution time. Replay identity and
  no-second-effect guarantees are proved within the durable run; no false byte-identical cross-run
  claim is made for the effect lifecycle.
- P2D multi-source conflict/correction is unchanged and remains the next domain-semantic packet
  after released-artifact and opt-in network-transport closeout.

## Release dependency

The packet consumes the ACE 0.5.0 candidate contracts and
`ace-reference-workspace-action>=0.1.0,<0.2` in cross-repository acceptance. The currently released
World distribution remains 0.8.0 and retains its prior dependency metadata. After ACE Core 0.5.0
and the adapter are public, the release-closeout change will set the true dependency floor, bump the
World and source-adapter distributions, refresh the lock, and reproduce the journey from installed
artifacts. Until then, this is source-checkout candidate evidence, not a completed World
Intelligence 0.9.0 release claim.
