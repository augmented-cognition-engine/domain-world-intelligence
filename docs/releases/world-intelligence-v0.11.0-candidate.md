# World Intelligence 0.11.0 AI Command Center release candidate

Status: **candidate — publication and public-index reproduction pending**

## Promise

World Intelligence 0.11.0 is the first released domain experience designed to make the ACE
Intelligence Operating System tangible. A user launches shared Atrium, follows a durable
Connect → Map → Watch → Brief onboarding journey, sees attributable AI sources and exact evidence,
and receives a cited first Brief without World creating a separate dashboard, store, or authority
path.

The Brief and its supporting Case, Shift, and Signal use a fixed decision-readable grammar—**What
changed / Why it matters / How we know / When it changed**—before presenting unknowns and evidence
limits. The Brief carries the specific World claim; supporting resources use invariant type meaning,
exact timing, and governed lineage. Epistemic caution remains visible, but it cannot replace the
intelligence itself.

## Acceptance gate

- The complete World domain and connector suites pass against public Core 0.8.1.
- The root wheel contains exactly the declared JSON resources, including the AI onboarding profile
  and source catalog, and contains no Python, adapter code, entry points, or install hooks.
- The root wheel builds reproducibly, passes strict Twine validation, and installs outside both
  source checkouts with only public Core 0.8.1.
- The source adapter remains separate, versioned, reviewed, and absent from the root dependency
  closure.
- The eight-revision Builder session reaches `first_briefing_ready`; the immutable Atrium page
  preserves source, connection, observation, entity, shift, signal, case, Brief, monitor,
  subscription, agent, and provenance identities.
- Desktop and mobile demo acceptance passes without horizontal overflow or uncaught console errors.

## Boundaries

The release uses reviewed recorded captures. It does not claim network freshness, autonomous
refresh, independent corroboration merely from publisher count, general AI-market completeness,
automated recommendation quality, publication authority, or beneficial impact. Proposed sources
remain proposals until separately admitted through a reviewed connector.

After publication, a separate closeout will bind the exact tag, workflow, artifact hashes,
public-index installation, demo reproduction, and observed limitations.
