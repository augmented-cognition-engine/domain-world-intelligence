# World Intelligence 0.9.0 — Reality Brief into reviewed action

**Release status:** released 2026-08-10. The
[`v0.9.0` GitHub Release](https://github.com/augmented-cognition-engine/domain-world-intelligence/releases/tag/v0.9.0)
and [`0.9.0 PyPI distribution`](https://pypi.org/project/ace-domain-world-intelligence/0.9.0/)
are public.

## Install target

```bash
uv add "ace-domain-world-intelligence==0.9.0"
# or
pip install "ace-domain-world-intelligence==0.9.0"
```

Requires Python 3.12 and `ace-core>=0.5.0,<0.6`.

## What ships

- an inert, JSON-only World Intelligence Domain Pack containing no executable code;
- the original prepared intelligence fixtures and official-source activation pack;
- a new five-module Federal Register monitor pack over two exact FCC records;
- declarations for the stable monitored entity, categorical Shift, routed Signal, personas, and
  six-claim/two-citation Reality Brief;
- conformance evidence for the complete official-record → Brief → Decision → reviewed local export
  journey.

The executable Federal Register connector remains a separate optional distribution. The reviewed
workspace effect is implemented by ACE Core's separately released reference action adapter.
