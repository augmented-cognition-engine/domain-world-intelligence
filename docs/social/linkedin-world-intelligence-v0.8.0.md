We just crossed an important line with ACE World Intelligence: from a frozen intelligence demo to
the first governed official-source admission.

One Federal Register document now enters through the same domain-neutral ACE boundary we designed
for any intelligence vertical:

entity graph → observation → signal → shift → brief → decision feedback

This release stops deliberately at the first step.

The source adapter is separately versioned and read-only. It is bound to one exact artifact, URI,
actor, source definition, and expiring authority grant. One capture creates five atomic LIVE
records: acquisition receipt, source snapshot, Observation, Entity Snapshot, and admission receipt.

Then we tested the part that matters: exact replay and fresh-service restart replay reopened the
same evidence without capturing it again.

We also kept the epistemic boundary visible. FederalRegister.gov is labeled as not the official
legal edition, and the corresponding govinfo PDF is retained as the verification reference. The
system does not jump from “a document exists” to “here is what you should believe or do.” No Signal,
Shift, Brief, publishing, persuasion, or external action is created by this packet.

The deeper architecture win is that we did not modify the ACE kernel and did not put code in the
Domain Pack. The existing World Intelligence scenario also stayed byte-identical. A new sensing
capability was added as configuration + a governed adapter, exactly as the platform thesis requires.

This is still a developer-preview contract proof using a recorded, network-free transport response—not
a production news product. But it is a concrete step toward an open intelligence platform where the
kernel stays invariant and domains supply vocabulary, sources, and policy.
