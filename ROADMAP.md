World Intelligence versions independently from ACE Core. It validates the shared Core +
Intelligence platform through public-issue sensemaking without moving World vocabulary, policy, or
source code into the platform.

## Invariant boundary

The Domain Pack never executes code, grants authority, fetches a source, publishes content, targets
people, or silently changes policy. Core + Intelligence own the invariant machinery; this
repository owns World vocabulary, source mappings, policies, connectors, fixtures, and product
evidence.
